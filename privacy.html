Privacy policy

Effective November 18, 2026

This policy describes the personal desktop connection named linux Server Eslam, operated by Eslam Nawar.

Data used and purpose

The connection requests Google Drive authorization to list and read files, upload selected files, and maintain folders and prior versions. The Google authorization scope permits creating, editing, and deleting files in the authorized account. The current local configuration targets the owner’s designated project folder; this folder selection does not narrow the underlying Google authorization scope.

Where data is processed

File transfers run on the owner’s Linux computer using rclone and communicate with Google Drive. OAuth credentials and tokens are stored in the owner’s local configuration. File content may be cached locally for on-demand access. This public information website does not receive Drive file content, passwords, or OAuth tokens.

Use and disclosure

Google user data accessed through this connection is used for the owner’s file browsing, synchronization, and backups. It is not sold, used for advertising, or used to train generalized AI or machine learning models. File content is transmitted to Google Drive for storage. This connection does not intentionally disclose that content to other recipients.

Retention and control

Uploaded files and saved prior versions remain until the owner removes them. Deleting a local source file does not automatically remove its cloud copies or prior versions. Local caches and local backup copies have separate retention. The owner can stop the local synchronization service and remove local configuration or cache files.

Google access can be revoked through Google Account third-party connections. Revocation stops future authorized access but does not delete files already stored in Drive or on the computer.

This website

These static pages have no analytics scripts, sign-in form, or file upload feature. GitHub Pages hosts them and may process ordinary request metadata under GitHub’s privacy statement.
